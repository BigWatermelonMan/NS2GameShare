# NS2GameShare

[English](README.md)

Switch 2のローカルおすそわけ通信に参加し、PCで映像・音声を再生する実験的なWindowsクライアントです。
コントローラー・キーボード・マウスで操作できます。配信側には対応ゲームを起動したSwitch 2が必要です。
任天堂とは関係のない独立したプロジェクトです。

## 必要なもの

- Windows x64、Media Foundation、対応するGPUドライバー。
- 次のいずれかの無線ブリッジ構成。

| 接続設定 | 機材 |
| --- | --- |
| ESP32 + FX2LP | M5Stack BasicとFX2LP。[配線ガイド](firmware-basic/README.md)に従って接続 |
| ESP32 (Native USB) | ネイティブUSBを使用するESP32-C5。USB帯域は前者より低め |

基板に対応するファームウェアを使用してください。ほかのESP32基板への対応には移植作業が必要です。
自分の`prod.keys`とGameShareパスフレーズも必要です。これらは付属しません。
対応する抽出元は[パスフレーズの抽出手順](docs/PASSPHRASE.md#日本語)を参照してください。

## 使い方

1. [ビルドとファームウェアの導入手順](docs/BUILD.md)に従って準備します。
2. `client-windows/target/release/NS2GameShare.exe`を起動します。
3. サイドバーで日本語／Englishを選択します。
4. 「接続」で参加者名・接続方法・認証ファイルのパスを設定します。
   「ESP32 + FX2LP」ではFX2 RAMファームを選び、自動ロードを有効にします。
5. Switch 2でおすそわけ通信の募集を開始し、「保存して接続」を押してからSwitch 2側で参加者を承認します。
6. ゲーム画面をクリックして操作します。終了時は設定画面の「切断」を押します。

[設定と既定の操作](client-windows/README.md)・[コントローラーとマウスの設定](docs/INPUT.md#日本語)

## 既知の制限

- 激しい動きなどでブロックノイズや音切れが発生することがあります。
- DS4のUSB／Bluetooth接続に対応しています。XInputとSwitchプロコンは実機検証が限定的です。
- マウスのジャイロ割り当ては実験的機能で、ゲーム内動作は未検証です。
- 解像度の指定は配信側の対応に依存します。操作から表示までの遅延は未測定です。
- ホスト署名の検証は未実装です。信頼できるホストにのみ接続してください。
